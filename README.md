This is a Code::Blocks project to explore it you need:

1. Code::Blocks installed
2. GNU GCC Compiler installed (ususaaqlly comes with Code::Blocks, if not refer to https://docs.google.com/spreadsheets/d/1sFAcV07JyNWNl--DZKG-E_ioQFrZzHq1a618kNSAWO8/edit?usp=sharing)

Steps:
1. Download the .zip archive
2. Extract the contents to the desired location on your PC
3. Look inside the extracted folder for a .cbp file and open it with Code::Blocks
